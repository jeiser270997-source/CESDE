ENUNCIADO:
5. Elaborar un algoritmo que calcule el salario neto a pagar a un
trabajador teniendo en cuenta su tipo de vinculación laboral:
FIJO o TEMPORAL.
Para cualquier trabajador se digita el nombre, tipo de vinculación
(1 para FIJO, 2 para TEMPORAL) y número de horas trabajadas en el mes.
- Si es FIJO: Se digita el valor de la hora, el monto de bonificaciones
  y el monto de deducciones.
  Salario Neto = (horas_trabajadas * valor_hora) + bonificaciones - deducciones.
- Si es TEMPORAL: La tarifa de la hora es fija de $6.000 COP por hora base,
  no recibe bonificaciones ($0) ni se le aplican deducciones ($0).
  Salario Neto = horas_trabajadas * 6000.
El programa debe imprimir el desglose completo del pago del trabajador.

============================================================

DATOS DE ENTRADA:
nombre = ""
tipo_trabajador = 0
horas_trabajadas = 0
valor_hora = 0.0
bonificaciones = 0.0
deducciones = 0.0

PROCESO:
SI (tipo_trabajador == 1) ENTONCES
    tipo_texto = "FIJO"
    // Solicitar valor_hora, bonificaciones y deducciones
    salario_bruto = horas_trabajadas * valor_hora
    salario_neto = salario_bruto + bonificaciones - deducciones
SINO
    tipo_texto = "TEMPORAL"
    valor_hora = 6000.0
    bonificaciones = 0.0
    deducciones = 0.0
    salario_bruto = horas_trabajadas * valor_hora
    salario_neto = salario_bruto
FIN SI

DATOS DE SALIDA:
nombre
tipo_texto
horas_trabajadas
valor_hora
salario_bruto
bonificaciones
deducciones
salario_neto
